Need a part number or a price while you're with a customer? The **Products** section is a searchable, read-only copy of the catalog, synced nightly from Synergy.

## How to look something up

1. Tap **Products** in the menu.
2. In the search box, type a **product number**, part of a **description**, or an **item code** (for example, "seal kit", "12345", or "0576-36").
3. Results appear as you type. Each shows the item number, description, and unit price. When an item carries a second description line from Synergy — which is where item codes usually live — it appears underneath the main description.

That's it — the catalog is read-only here, so there's nothing to save or change.

## Good to know

- Search matches the item number, words in the description, **or** the item code in Description 2 — so you don't need the exact number.
- Synergy splits an item's text across two description fields. The second one often holds the item code the office orders against, so it's shown on its own line rather than run together with the first.
- Pricing and items come from Synergy. If something's wrong or missing, it gets corrected in Synergy and updates here on the next nightly sync.
- The list shows when each item was **last synced**, so you can tell how current it is.
